# Sales & Revenue Analysis Dashboard

## Objective
Analyze sales and revenue data using Power BI.

## Features
- Total Sales KPI
- Total Profit KPI
- Revenue Trend Analysis
- Top Performing Products
- Regional Sales Analysis
- Interactive Filters and Slicers

## Tools Used
- Power BI
- Excel/CSV
- GitHub

## Outcome
Built an interactive dashboard for business insights and KPI tracking.
